# eziq1/tap

Homebrew tap for [golauncher](https://github.com/eziq1/golauncher), a Raycast-style keyboard launcher written in Go.

```sh
brew install --cask eziq1/tap/golauncher
```

Upgrade with `brew upgrade --cask golauncher`. The app is not notarized by Apple; see the cask's caveats for how to open it the first time.

The cask is generated by [`scripts/release/brewcask`](https://github.com/eziq1/golauncher/tree/main/scripts/release/brewcask) for each release.
